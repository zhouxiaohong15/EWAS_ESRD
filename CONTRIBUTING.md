# Contributing to EWAS_ESRD

We welcome contributions to improve the EWAS_ESRD project!

## How to Contribute

1. **Fork** the repository to your GitHub account.
2. **Create a new branch** for your changes:
   `ash
   git checkout -b feature/your-feature-name
   `
3. **Make your changes** and commit them with clear commit messages.
4. **Push** to your fork and open a **Pull Request**.

## Pull Request Guidelines

- Provide a clear description of the changes and the motivation behind them.
- Keep changes focused and avoid unrelated modifications.
- Ensure your code is well-documented, especially if adding new analysis scripts.
- Reference any related issues if applicable.

## Reporting Issues

If you find a bug or have a suggestion, please open an issue on GitHub with:
- A clear and descriptive title.
- A detailed description of the issue or proposed change.
- Steps to reproduce (if applicable).

## Code Style

- R scripts should follow standard R conventions.
- Shell scripts should include shebang lines and be executable.
- Use meaningful variable and function names.
- Add comments for non-obvious logic.

## Questions

Feel free to open an issue for any questions about the project.

Thank you for helping improve EWAS_ESRD!
